## 📖 About the Project

**Dev-Hive** is a modern website created for a student business project representing a fictional software development company.

The website was designed to present the company's services, technologies, projects and contact information through a modern and interactive interface.

The main goal was to create a professional-looking website while applying concepts of **component-based development, responsive design and user interaction**.

---

## ✨ Features

- 🎨 Modern dark interface
- 📱 Responsive design
- ⚛️ Component-based React architecture
- ⚡ Vite development environment
- 🧩 Interactive service cards
- 💻 Technology showcase
- 🚀 Projects section
- 📩 Contact form
- 🖱️ Hover and cursor interactions
- 🎯 Smooth UI animations
- 🐝 Dev-Hive branding
